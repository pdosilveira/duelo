# Duelo de Faixas

App web pessoal que descobre suas músicas favoritas por comparações em pares (Glicko-2 com períodos fracionários, seleção adaptativa de duelos). Site 100% estático, dados no `localStorage`.

- `npm test` — testes (node:test, sem dependências)
- `node test/simulate.js [duelos por música] [semente]` — simulação adaptativa vs. aleatória

Prévias e capas fornecidas pela Apple (iTunes Search API).
